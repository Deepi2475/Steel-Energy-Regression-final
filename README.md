# Steel Plant Energy Consumption ML Project

A full production-style ML project for energy consumption regression using the Kaggle "Steel Plant Energy Consumption Data" dataset.

## Project Overview

This project implements:
- Robust data cleaning and preprocessing
- Time-based data splitting (35% train, 35% validate, 30% test)
- H2O AutoML for model selection
- Manual training of three models (XGBoost, LightGBM, RandomForest) with MLflow logging
- Remote MLflow Tracking Server (AWS EC2 + Neon Postgres + S3)
- Model registry and comparison
- FastAPI prediction service
- Model drift analysis using Evidently and NannyML

## Setup

1. Install UV (if not already installed):
   ```bash
   pip install uv
   ```

2. Initialize environment:
   ```bash
   uv sync
   uv lock
   ```

3. Download the dataset:
   - Place `steel_energy.csv` in `data/raw/` directory
   - Ensure column names match the configuration

4. Configure environment:
   - Copy `config/mlflow.env.example` to `config/mlflow.env` and fill in your MLflow tracking URI
   - Copy `config/aws.env.example` to `config/aws.env` and fill in AWS credentials
   - Copy `config/neon.env.example` to `config/neon.env` and fill in Postgres connection info

## Execution Workflow

### 1. Data Preparation
```bash
uv run python scripts/01_ingest_and_clean.py
uv run python scripts/02_time_split.py
```

### 2. H2O AutoML (Optional)
```bash
uv run python scripts/03_run_h2o_automl.py
```

### 3. Model Training
```bash
# Set MLflow environment variables
set -a; source config/mlflow.env; set +a  # Linux/Mac
# or
Get-Content config/mlflow.env | ForEach-Object { if ($_ -match '^([^=]+)=(.*)$') { [Environment]::SetEnvironmentVariable($matches[1], $matches[2]) } }  # Windows PowerShell

uv run python scripts/04_train_xgboost.py
uv run python scripts/05_train_lightgbm.py
uv run python scripts/06_train_randomforest.py
```

### 4. Model Registration
```bash
uv run python scripts/07_register_models.py
```

### 5. FastAPI Deployment
```bash
uv run uvicorn api.main:app --host 0.0.0.0 --port 8000
```

Test with:
```bash
curl -X POST http://localhost:8000/predict_model1 \
  -H "Content-Type: application/json" \
  -d @api/sample_requests/single.json
```

### 6. Drift Analysis
```bash
uv run python scripts/08_drift_evidently.py
uv run python scripts/09_drift_nannyml.py
```
